# Design

The review page design lives in code: `demo/src/ReviewPage.tsx` is the
screen, `demo/src/reviewData.ts` is its data, and `demo/src/components/ui/`
holds the two shadcn-style primitives it uses. Run `npm run demo` from the
repo root to see it.

Add design source files (Figma exports, screenshots, redlines) to this folder
as they land; keep the React demo as the reference for behavior.
